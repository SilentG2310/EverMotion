Calibration Development and Mid-Project Demonstrations

Work Done

  • Started developing the Energy Calibration Matrix mini-game (Game 12) in Unity, implementing and testing the initial gameplay mechanics ahead of gesture control integration.
  • Began building the System Calibration UI screen with webcam input and explored using MediaPipe movement data for calibration; renamed "System Synchronisation" to "System Calibration" for clarity.
  • Worked with Joshua to connect calibration data with the profile system, reviewing the data flow so results are correctly linked to each player.

Reflection
